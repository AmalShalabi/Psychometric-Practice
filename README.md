# تعلم الإنجليزية - تطبيق تعليمي تفاعلي

تطبيق تعليمي تفاعلي لتعلم اللغة الإنجليزية للمرحلة الثانوية وامتحانات البسيخومتري، مصمم خصيصاً للطلاب العرب.

## 🌟 المميزات

### 📚 المحتوى التعليمي
- **المفردات**: 25+ كلمة إنجليزية مع ترجمات وأمثلة
- **القواعد**: دروس تفاعلية مع اختبارات فورية
- **القراءة**: نصوص متدرجة الصعوبة مع أسئلة الفهم
- **البسيخومتري**: اختبارات محاكاة مع نتائج مفصلة

### 🎮 التلعيب
- نظام النقاط (XP) والمستويات
- سلسلة الأيام المتتالية
- إنجازات وشارات
- تتبع التقدم الأسبوعي

### 🎨 التصميم
- واجهة RTL باللغة العربية
- تصميم متجاوب للهواتف والأجهزة اللوحية
- ألوان متدرجة من الأزرق إلى البنفسجي
- رسوم متحركة سلسة مع Framer Motion

### 📱 التقنيات المستخدمة
- **React 18** - مكتبة واجهة المستخدم
- **Vite** - أداة البناء السريعة
- **TailwindCSS** - إطار عمل CSS
- **Framer Motion** - الرسوم المتحركة
- **React Router** - التنقل بين الصفحات
- **Lucide React** - الأيقونات

## 🚀 التشغيل

### المتطلبات
- Node.js 16+ 
- npm أو yarn

### التثبيت
```bash
# استنساخ المشروع
git clone <repository-url>
cd eng-arabic-app

# تثبيت التبعيات
npm install

# تشغيل التطبيق
npm run dev
```

### البناء للإنتاج
```bash
npm run build
npm run preview
```

## 📊 البيانات

### إضافة مفردات جديدة
قم بتعديل `src/data/vocabulary.json`:

```json
{
  "id": 26,
  "english": "New Word",
  "arabic": "كلمة جديدة",
  "meaning": "المعنى",
  "example": "Example sentence",
  "exampleArabic": "جملة المثال",
  "tip": "نصيحة مفيدة"
}
```

### إضافة دروس قواعد
قم بتعديل `src/data/grammar.json`:

```json
{
  "id": 6,
  "title": "عنوان الدرس",
  "description": "وصف الدرس",
  "content": [...],
  "quiz": [...]
}
```

## 🔧 التطوير

### إضافة صفحة جديدة
1. أنشئ مكون جديد في `src/pages/`
2. أضف المسار في `src/App.jsx`
3. أضف رابط في `src/components/Layout.jsx`

### إضافة رسوم متحركة
استخدم Framer Motion:

```jsx
import { motion } from 'framer-motion'

<motion.div
  initial={{ opacity: 0, y: 20 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: 0.5 }}
>
  المحتوى
</motion.div>
```
